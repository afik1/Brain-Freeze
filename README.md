# Brain Freeze 🍦

A small frontend development workshop for practicing AI-assisted development with coding agents.

The backend is already implemented.

Your work is in:

`apps/web/`

## Getting started

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npm run dev
```

Frontend:

`http://localhost:5173`

API:

`http://localhost:3001`

## Before you start

Read:

`docs/WORKSHOP.md`

API reference:

`docs/API.md`

Project instructions for coding agents:

`AGENTS.md`

Available workflows:

`.agents/workflows/`

## Verification

Run tests:

```bash
npm run test
```

Before finishing:

```bash
npm run verify
```

## Important

The API is workshop infrastructure and should not be modified.

The business requirements will be presented during the workshop.

Do not try to infer the full assignment from the repository before the workshop begins.
