# Brain Freeze — Workshop Brief

ברוכים הבאים. יש לכם שעה.

---

## המצב

Brain Freeze היא גלידרייה אומנותית שנפתחת הערב.

הבעלים הסתכל על האתר הקיים ופרש את פרצופו:

> *"זה נראה כמו מערכת ניהול משנת 2007."*

המשימה שלכם: לבנות חוויית הזמנה אמיתית ללקוחות לפני שהדלתות נפתחות.

ה-API מוכן. הטעמים בפנים. מה שחסר הוא frontend שלקוח היה רוצה להשתמש בו.

---

## מה לבנות

לקוח צריך להיות מסוגל:

- לראות את טעמי הגלידה
- להבין את המחיר, התיאור והקטגוריה של כל טעם
- לדעת אם טעם הוא טבעוני
- לראות כאשר טעם אינו זמין
- לסנן טעמים לפי קטגוריה
- לסנן לטעמים טבעוניים בלבד
- להוסיף טעמים להזמנה ולשנות כמויות
- להסיר פריטים מההזמנה
- לראות את המחיר הכולל
- לשלוח הזמנה
- לקבל אישור ברור אחרי הזמנה מוצלחת

האפליקציה צריכה גם:

- להציג מצב טעינה בזמן שהנתונים מגיעים
- לטפל בשגיאות API בצורה שלא תשאיר את הלקוח אבוד
- לעבוד בצורה סבירה על מסך קטן

> **אין צורך בעיצוב מושלם. המטרה היא מוצר עובד ושמיש.**

## איפה לעבוד

**הסביבה שלכם היא `apps/web/`.**

ה-API כבר רץ ומתועד ב-`docs/API.md`.
אין לשנות את ה-API.

להרצה:

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173  
API: http://localhost:3001

## איך לעבוד עם האייג'נט

הסדנה הזו לא עוסקת רק בבניית UI מהר. היא מתרגלת **עבודה נכונה עם AI agent**.

### לפני שמתחילים לממש

בקשו מהאייג'נט:

1. לקרוא את הדרישות ולהבין מה צריך לבנות
2. לחקור את מבנה הריפו
3. לקרוא את תיעוד ה-API (`docs/API.md`)
4. לזהות אילו קבצים רלוונטיים לעבודה
5. להציע תכנית — מה לבנות, באיזה סדר
6. לזהות הנחות שהוא מניח

**שמרו את התכנית הראשונית בקובץ `WORKSHOP_PLAN.md` בשורש הפרויקט.**

תכנית כתובה שאפשר לחזור אליה שווה יותר מתכנית שחיה רק בצ'אט.

### במהלך העבודה

השתמשו בפידבק אמיתי מהמערכת:

- שגיאות build ו-TypeScript הן מידע — השתמשו בהן
- בדקו תגובות API בפועל לפני שמניחים משהו לגבי הצורה שלהן
- כשמשהו לא עובד — נסו להבין מה קורה לפני שמאתחלים את השיחה

כשהאייג'נט טועה, עדיף לתקן בהקשר הקיים מאשר להתחיל מחדש.

### לפני הסיום

```bash
npm run verify
```

ואז:

- בדקו ידנית את המסלול המרכזי מקצה לקצה
- בקשו מהאייג'נט לעשות review לשינויים:
  - האם כל הדרישות מומשו?
  - האם השתנו קבצים שלא היו אמורים להשתנות?
  - האם יש מקרי קצה שלא טופלו?
  - האם נוצרה מורכבות מיותרת?
